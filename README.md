# PDFGator

Um programa para modificar e organizar seus pds

## Habilidades
### Organização de paginas
VocÊ consegue mudar a ordem que as paginas aparecem

![move](https://github.com/user-attachments/assets/cd6d06ff-f65b-4901-b97d-2398b0b4a31e)

### Visualizar
Você consegue visualizar a pagina de maneira dinamica

![view](https://github.com/user-attachments/assets/0a8aa83e-c02e-414d-8877-ae42c775feb7)


### Salvando como imagem
Você consegue salvar a pagina do pdf como um jpg ou png

![save](https://github.com/user-attachments/assets/538f3642-1bd1-4a21-9d9e-3380acdd8860)

### Rotação
Você pode rotacionar a sua pagina

![rotate](https://github.com/user-attachments/assets/de285255-b40d-4b6c-a3e9-48802d6f1198)


Outras habilidades incluem : usar jpg / png como paginas no pdf, mesclar e comprimir os pdfs e adicionando arquivos de um diretorio
